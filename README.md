# Сократи время YouTube

Сидел я на YouTube, но долговато переходить на youtube.com/watch, да и шорты я не люблю, но иногда где-то как-то.

Вообщем я создал скрипт для всяких Monkey, который позволяет быстрее кататься по видосам.

Если вы хотите загружать Shorts в обычном виде, а не в меню просмотра горизонтальных видео, то нажмите на иконку вашего Monkey расширения.
